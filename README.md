# Airline Reservation System - MySQL

## Project Overview

This project is a database management system for an Airline Reservation System.
It is developed using MySQL to manage passengers, airlines, airports, flights,
bookings, payments, aircrafts, and crew information.

## Technologies Used

- MySQL
- SQL

## Database Tables

1. Passengers
2. Airlines
3. Airports
4. Aircrafts
5. Flights
6. Bookings
7. Payments
8. Crew

## SQL Concepts Used

- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- WHERE
- LIKE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- INNER JOIN
- Multiple Table JOIN
- Subqueries

## Project Queries

The project contains SQL queries for:

- Passenger analysis
- Flight analysis
- Booking analysis
- Payment analysis
- Airline performance
- Revenue analysis
- Airport analysis
- Crew analysis
